🧠 MENACE: A Reinforcement Learning Experiment

Play Tic-Tac-Toe against MENACE and watch its matchbox change with experience.

What is MENACE?

In 1961 the British scientist Donald Michie built a machine that learns to play tic-tac-toe. It had no computer. It was made of about 300 matchboxes and a bag of coloured beads.

At first MENACE plays at random and loses a lot. Nobody teaches it any strategy. It gets better just by playing, winning and losing. This page is a copy of that machine.

How MENACE picks a move

  1. There is one matchbox for each board position MENACE can meet. The position is drawn on the lid.
  2. Inside each box are beads. Each colour stands for one empty square on that board.
  3. On its turn, MENACE finds the box that matches the board, shakes it, and pulls out one bead without looking. It plays on the square that bead stands for.

So a move with many beads is likely to be picked. A move with few beads is rarely picked.

How MENACE learns

When the game ends, MENACE goes back to every box it used and changes the beads:

  • It won: each move it played gets 3 extra beads.
  • It drew: each move gets 1 extra bead.
  • It lost: each move loses 1 bead.

Moves that led to wins collect beads and get picked more often. Moves that led to losses lose beads and slowly disappear. That is all there is to it, and it is enough to learn the game.

A small example. On an empty board, all four corners play the same way: they are mirror copies of each other. The same is true of the four edges. So MENACE's first box only needs three bead colours: one for "a corner", one for "an edge" and one for "the centre". It starts with 8 beads of each colour, 24 beads in total. Each colour has 8 of the 24 beads, so each kind of move has a 1-in-3 chance. When a corner bead is drawn, MENACE plays one of the corners.

Now MENACE plays an edge and loses, so the edge colour drops to 7 beads. Next game it plays the centre and wins, so the centre colour goes up to 11 beads. The box now holds 8 + 7 + 11 = 26 beads. The centre has 11 of them, so MENACE now opens in the centre a bit more than 4 times in 10.

What if a box runs out of beads?

Then MENACE has no move it trusts there, so it gives up. That counts as a loss, so the moves that led into that position lose beads too. Over time MENACE learns to stay away from such positions.

There is one exception. If the box for MENACE's first move empties (for example because you beat it many games in a row), MENACE would give up before making any move. No beads would change, so it would give up in every game after that, forever. To avoid this dead end, this version refills that box with fresh beads and tells you so. MENACE then starts learning its openings again. Michie's machine had no such rule.

What you see on this page

  • MENACE Matchbox: the beads in the box MENACE just used, one row per possible move.
  • Matchbox report: after each game, every box MENACE used, with its beads before and after.
  • Learning Level: how much of MENACE's beads sit on the best moves. It also plays a test against a flawless player. Against a flawless player the best anyone can do is a draw, so a fully trained MENACE never loses.
  • Automated training: MENACE plays thousands of games against an opponent who moves at random. This is much faster than playing it yourself.

Things to try

  1. Play 10 games. Read the matchbox report after each one.
  2. Train 1,000 games. Then check the Learning Level panel.
  3. Reset MENACE and compare how fast it learns.

Why does this matter?

MENACE learns by trial and error with rewards. Computer scientists call this reinforcement learning. It is the same basic idea behind programs that taught themselves to beat world champions at chess and Go. Those programs use huge computers instead of matchboxes, but the principle is the same: try things, keep what works.

MENACE also shows a hard problem. The reward comes only at the end of the game, but every earlier move gets the credit or the blame. A good move in a lost game is punished too. Only over many games do the good moves come out on top.

Why only about 300 matchboxes?

Tic-tac-toe has thousands of possible boards, but MENACE needs far fewer boxes:

  • Turned or flipped boards are the same game. A board turned on its side, or seen in a mirror, plays exactly the same. One box covers all these copies. For the same reason, moves that are mirror copies share one bead colour. The empty board only needs three: corner, edge and centre.
  • Only MENACE's own turns need boxes. It never chooses your moves.
  • No box for the last square. When only one square is left, there is no choice to make.

How many beads does a new box get?

Each board position has its own matchbox. The starting number of beads depends on how far into the game that position comes:

These are only the starting counts. After every game, wins, draws and losses change the beads in each box that was used. Late boxes start with fewer beads so they learn faster: a single loss can empty a 1-bead move, while the empty-board box hardly notices. That makes sense, because a loss is usually caused by the last few moves.

Michie's machine started with 4, 3, 2, 1. This version gives the early boxes more beads (8, 4, 2, 1, as in Matthew Scroggs's MENACE), so a strong player cannot empty the first box so quickly. The box counts are for MENACE moving first, as in the original. When MENACE plays second, the same pattern is used for its turns.

For the curious: the exact count

There are 5,478 legal boards. Of these, 2,423 have X to move with the game still open. Removing the 222 boards where only one square is left gives 2,201. Merging turned and flipped copies gives 304, exactly the number Michie used. When MENACE plays O instead, it needs 289 boxes.

How this version differs from Michie's original

  • More starting beads in early boxes: 8, 4, 2, 1 instead of 4, 3, 2, 1.
  • The first-move box is refilled when it empties, so MENACE never gets stuck giving up every game.
  • MENACE can also play second (as O). Michie's MENACE always moved first.

Limits

MENACE works because tic-tac-toe is small. A game like chess has far too many positions to give each one a box. Modern systems use neural networks instead. They learn from similar positions at once, so they do not need to see every position.
